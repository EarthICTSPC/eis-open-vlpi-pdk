## Independence rule

An external LLM must receive the frozen evidence and the admissibility rules, but **not** the previously selected SWARM-001 population or dependency graph.

Each model returns its own:

1. transformation population;
2. contracts;
3. dependency graph;
4. admissibility rejections;
5. minimality argument;
6. unresolved contracts.

A separate verification pass adjudicates each derivation.

## What we are measuring

We are **not** measuring which LLM is "right."

We are measuring whether the observed evidence is sufficient to constrain a stable transformation ontology.

- convergence → stronger evidence that the specification is constraining the design space;
- disagreement → useful evidence of missing/ambiguous contracts;
- new required transformation → candidate requirement generated by the empirical result;
- unnecessary transformation → candidate for reduction.
